# Movies Unloaded

Local-first Android app to browse movies & TV shows — your cinema in your pocket.

🌐 **Site:** https://movies-unloaded-app.pages.dev/
📢 **Channel:** https://t.me/movies_unloaded_network
🤖 **Movie Bot:** https://t.me/Movies_desire_bot

## About

Movies Unloaded is an OTT-style app built around one promise: **your data stays
on your device**. Watchlist, favorites, history, continue-watching progress
and your taste profile live only on your phone — no account, no sign-up,
nothing personal ever uploaded.

## Features

- 🔍 Browse, search & rich details for movies and series
- 📌 Watchlist, favorites, history and per-episode continue-watching
- 🧠 On-device taste recommendations with match scores and signal captions
- 📺 Multi-server playback with automatic failover
- ⏭ Auto Play Next, Up Next rails and season/episode picker for series
- 🔔 Push alerts for new releases with tap-to-open links + in-app history
- 📩 Missing-title requests straight from search via Telegram
- 🛡 Anonymous analytics only — no tracking, no ads

## Framework & stack

- **Flutter (Dart)** — single codebase, Material 3 UI
- **Firebase backend services** — push messaging, analytics, app distribution
- **SQLite (on-device)** — local library, history and recommendations cache
- **Cloudflare Pages** — this landing site

> API keys, provider endpoints and server details are intentionally kept
> private and are never committed to this repository.
